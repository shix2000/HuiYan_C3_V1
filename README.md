# 慧演 HuiYan

慧演是以 ESP32-C3 與 MPU-6050 開發的穿戴式簡報控制器，透過 BLE HID 鍵盤與滑鼠連接電腦，以翻腕、傾斜及按鍵操作簡報與游標。

目前為持續調校中的原型，使用 PlatformIO 與 Arduino 框架開發。程式已實作不等同實機驗收通過；各功能證據見「目前驗證狀態」。

## 功能

- 簡報：左旋下一頁、右旋上一頁；GPIO3 單擊下一頁、雙擊上一頁。
- 滑鼠：傾斜控制相對游標速度、回中停止；GPIO3 單擊左鍵、雙擊右鍵。
- GPIO3 長按 3 秒切換簡報／滑鼠模式；開機預設簡報模式。
- GPIO6 獨立配對鍵，長按 2 秒開啟 BLE 配對窗口。
- 手動中立校正、可開關的簡報手勢自動中立恢復。
- 串列診斷、微捏按住時的六軸 CSV 採集。
- 斷線取消待決輸入，重連先釋放鍵鼠，不重播斷線期間的操作。

## 硬體與接線

目前穿戴端使用 ESP32-C3 Super Mini、MPU-6050、兩顆常開瞬時按鍵，以 USB 供電測試。

| 裝置／訊號 | ESP32-C3 接點 | 說明 |
|---|---|---|
| MPU-6050 SDA | GPIO4 | I²C 資料 |
| MPU-6050 SCL | GPIO5 | I²C 時脈，100kHz |
| MPU-6050 GND | GND | 共地 |
| MPU-6050 電源 | 3V3 | 確認實際模組支援 3.3V 供電，I²C 上拉應為 3.3V |
| 微捏／操作鍵 | GPIO3 ↔ 按鍵 ↔ GND | 內部上拉，按下為 LOW |
| 配對鍵 | GPIO6 ↔ 按鍵 ↔ GND | 內部上拉，按下為 LOW |

GPIO 編號不是排針的實體序號。四腳按鍵請選按下才導通的兩個接點；同側腳可能原本就相通。GPIO6 同時具有外部 JTAG 功能，使用該除錯介面時須重新規劃。

程式依序嘗試 MPU-6050 位址 `0x68`、`0x69`；目前保留 ±8g、±2000°/s、21Hz 濾波及約 50Hz 讀取設定。實際讀取採已檢查傳輸結果的 I²C burst read。

`platformio.ini` 使用 `esp32-c3-devkitm-1` 作建置板型；這是目前專案設定，不代表實際 Super Mini 的板級配置完全相同。USB CDC 用於診斷與採集，鍵鼠控制通路為 BLE。

## 快速開始與配對

1. 供電並開啟 115200 baud 串列監控。
2. 首次配對前先放開配對鍵，再長按 GPIO6 兩秒，或輸入 `p`，開啟 60 秒配對窗口。
3. 在電腦藍牙設定中配對 `HuiYan V0.4`。已連線或正在錄製資料時，不接受開啟新配對的請求。
4. 看到 `HID READY` 後放開操作鍵。既有 bonding 會保存；開機有配對紀錄時會廣播供重連。
5. 固定佩戴方向，進行中立校正，再開始操作。

配對使用 Just Works bonding，沒有 MITM 身分驗證保護。清除裝置端配對使用 `c`，也需在主機端移除舊裝置紀錄，再重新開啟配對窗口。

## 按鍵與模式操作

| 模式 | GPIO3 單擊 | GPIO3 雙擊 | GPIO3 長按 3 秒 |
|---|---|---|---|
| 簡報 | 下一頁（Page Down） | 上一頁（Page Up） | 切換至滑鼠模式 |
| 滑鼠 | 左鍵完整點擊一次 | 右鍵完整點擊一次 | 切換至簡報模式 |

- 雙擊窗為第一次放開到第二次按下的 300ms；每次短按須不超過 500ms。
- 單擊會等雙擊窗結束才送出，避免雙擊先產生一次單擊。
- 超過 500ms、未滿 3 秒就放開的按壓取消，不作點擊。長按只切換一次，須放開才能再操作。
- 滑鼠雙擊是一次右鍵，不是兩次左鍵；實體長按不是拖曳。本版無拖曳與滾輪。
- GPIO6 僅作配對，與 GPIO3 操作鍵分開；不會強制斷開已連線主機。

## 旋轉手勢與中立校正

目前已確認的佩戴方式為 **左旋下一頁、右旋上一頁**。程式實際以正 GY 對應下一頁、負 GY 對應上一頁；換手、翻轉或改變安裝方向可能改變映射，尚無左右手自動辨識。

1. 簡報模式、HID ready、非採集模式下，輸入 `n` 一次。
2. 放開兩顆按鍵，保持自然中立姿勢靜止。
3. 等到 `ARMING->READY reason=ready_neutral_confirmed` 才旋轉；`calibration_complete` 只是完成校正，尚須連續靜止致能。
4. 翻腕後回中，等下一次 `READY` 再做另一方向。

目前調校參數：

| 項目 | 設定 |
|---|---|
| 起動角速度 | 120°/s（GY） |
| 有效旋轉量 | 20～150° |
| 候選窗 | 500ms，不因前置動作延長 |
| 結束確認 | 低速低於 40°/s 連續 60ms，或合格去程後反向超過 40°/s 連續 60ms |
| 回正容許範圍 | 距校正重力方向 25° 內 |
| 重新致能 | 回正且連續靜止 300ms；成功輸出後另需至少 600ms 冷卻 |

另有有效去程時長、方向一致性與主軸能量檢查。小於 20° 的前置動作可在原候選窗內修正方向。成功後進入 `LOCKOUT`，回轉不另產生翻頁。按鍵操作、滑鼠模式、配對窗口及採集模式會關閉手勢輸出。

### 自動中立恢復

預設開啟，`a` 切換；此開關不保存，重開機恢復開啟。

在 `ARMING` 或 `LOCKOUT` 連續靜止但超出舊中立範圍達 5 秒後，開始額外 2 秒的穩定取樣。期間移動、姿態漂移、按鍵操作或通路停用就取消。完成後更新此次使用的中立與偏移估計，清除舊候選，再靜止 300ms 才致能，不補送事件。

這是受條件限制的恢復流程：長時間穩定停在偏轉姿勢也可能被視為新中立，無法只靠 IMU 確定使用者意圖。手動 `n` 仍可使用。此功能僅用於簡報手勢，不會在滑鼠持續傾斜時偷偷重設中立。

## 傾斜游標

1. GPIO3 長按 3 秒切至滑鼠模式，放開按鍵。
2. 靜止保持舒適姿勢約 1 秒，等到 `MOUSE READY`。
3. 相對中立的兩軸傾斜控制游標速度；持續傾斜持續移動，回中停止。
4. 單擊左鍵、雙擊右鍵；需要重定中立時輸入 `n`。

控制以重力向量與陀螺儀融合，建立相對於中立的兩個傾斜軸。啟動門檻 4°、停止門檻 3°，25° 滿速，上限 800 HID counts/s；實際畫面速度受主機游標設定、加速與縮放影響，並非固定像素速度。實際方向須依佩戴方式測試。

操作鍵按下至單／雙擊解析完成，及結束後 100ms，抑制游標位移且不補送距離。斷線、採集、切模式或 IMU 讀取錯誤會停止並清除位移狀態。重新連線需重新取中立。姿態偏離滑鼠中立超過約 60° 時停止並重新等待校正。5 秒無法完成中立取樣會提示繼續保持靜止，不強制啟動。

## 串列指令

115200 baud，指令為單一小寫字元；切換類指令請依回覆判斷狀態，避免重複輸入。

| 指令 | 功能與條件 |
|---|---|
| `p` | 未連線且非採集時，開啟 60 秒配對窗口 |
| `c` | 未連線且非採集時清除裝置 bonding；主機端也需移除舊配對 |
| `n` | 非採集時重定中立：簡報約 1.3 秒後致能；滑鼠約 1 秒靜止取樣 |
| `a` | 非採集時切換簡報手勢自動中立恢復，預設 ON |
| `g` | 切換旋轉手勢啟用／暫停，預設 ON；不關閉傾角滑鼠 |
| `v` | 切換手勢與傾角滑鼠診斷，預設 ON；不關閉辨識功能 |
| `r` | 切換資料採集模式；開啟後禁止操作 HID 輸出 |
| `u` / `d` | 已就緒的簡報模式測試上一頁／下一頁 |
| `h` / `j` / `k` / `l` | 已就緒的滑鼠模式測試左／下／上／右位移；非採集、按鍵無序列且沒有待釋放報告時可用 |

`n`、模式切換與重連會取消待決按鍵序列，須先放開操作鍵。應用程式須保持焦點；裝置不會自動切換或搶取簡報視窗焦點。

### 資料採集

輸入 `r`，放開 GPIO3，再按住錄製、放開結束。以 `r` 離開採集。

```text
# PINCH_START
time_ms,ax,ay,az,gx,gy,gz
...
# PINCH_END
```

實際 CSV 標頭於進入採集模式時先輸出，之後每段以 `PINCH_START`／`PINCH_END` 分隔。時間為開機後毫秒，加速度單位 **m/s²**，陀螺儀單位 **rad/s**；診斷中的角速度則換算為 **°/s**，兩者不可直接混用。採集期間會停用手勢及滑鼠診斷，避免混入 CSV。

`data/left.txt`、`data/right.txt` 是舊版旋轉資料，沒有完整佩戴、受測者與採集設定中繼資料，不能作為左右手分類或新版驗收通過證據。

### 常用診斷

- `GST GATE allow=1`：簡報手勢輸出條件開啟；滑鼠模式下 `allow=0` 是正常的互斥結果。
- `CALIBRATE -> ARMING -> READY`：完成校正與致能。
- `CANDIDATE -> LOCKOUT reason=ACCEPT`：有效手勢；`GST EVENT` 是辨識事件，`GESTURE NEXT/PREVIOUS` 表示 HID 報告成功排入傳送，不等同主機畫面已確認變更。
- `waiting_return_neutral`：需回校正姿勢，或在舒適姿勢以 `n` 重校正。
- `AUTO_CALIBRATE_BEGIN / CANCEL / COMPLETE`：自動恢復狀態。
- `MOUSE CALIBRATE_BEGIN / READY`、`MOUSE tilt`：滑鼠校正、傾角、速度、位移與抑制狀態。
- `IMU_READ_ERROR`、`MOUSE SAMPLE GAP`：感測資料異常；先確認接線與資料恢復。

## PlatformIO 編譯

安裝 VS Code、PlatformIO IDE，開啟本專案資料夾，在 PlatformIO 終端執行：

```powershell
pio run -e esp32-c3-devkitm-1
```

此指令**只編譯，不燒錄**。也可使用 VS Code 的 PlatformIO「Build」。首次編譯會依設定下載工具及相依，需網路連線。若一般終端找不到 `pio`，改用 PlatformIO 終端。

韌體建置產物位於 `.pio/build/esp32-c3-devkitm-1/`；`.pio/` 已由 `.gitignore` 排除。

開啟串列監控：

```powershell
pio device monitor -p COM7 -b 115200
```

`COM7` 僅為先前測試埠，請依實際裝置調整。

| 開發元件 | 目前版本／設定 |
|---|---|
| PlatformIO 平台 | `espressif32@8.0.0` |
| framework / board | `arduino` / `esp32-c3-devkitm-1` |
| 本機成功建置的 Arduino-ESP32 | 3.3.12；實際解析依平台套件而定 |
| Adafruit MPU6050 | 2.2.9 |
| Adafruit Unified Sensor | 1.1.15 |
| Adafruit BusIO | 1.17.4 |
| NimBLE-Arduino | 2.5.2 |

先前 NimBLE 2.3.6 組合出現 BLE 控制器初始化崩潰，已更新至 2.5.2，後續由使用者確認 HID 連線成功；目前不建議自行退回舊版。

## 程式結構

```text
platformio.ini       建置、相依與 USB CDC 設定
HuiYan_PRD.md        初始產品需求與驗收規劃
src/main.cpp         採樣、BLE 複合 HID、GPIO3 按鍵 FSM、通路與模式仲裁
src/Gesture.h/.cpp   旋轉手勢、校正、回轉確認、自動中立恢復與診斷
src/PairButton.h/.cpp GPIO6 配對鍵去彈跳與長按
src/TiltMouse.h/.cpp 傾角融合、中立校正、游標速度與位移
data/                舊版六軸旋轉資料
```

| GPIO3 單／雙／長按 | 已實作並編譯通過 | 最新雙擊上一頁、滑鼠左右鍵與時序邊界實測 |

最新功能整合版本已成功建置：RAM 約 7.9%、Flash 約 63.2%；數值會隨版本變動。傾角滑鼠版目前僅完成編譯，未由開發流程自動燒錄。

現行 150° 旋轉上限、25° 回正範圍及回轉確認流程依實測調校，與 PRD 原始 70°／10° 提案不同；應以現行程式與後續測試紀錄為準，不宣稱 PRD 全項通過。ESP-NOW／S2 USB Dongle、電池續航與左右手自動辨識尚未實作。
